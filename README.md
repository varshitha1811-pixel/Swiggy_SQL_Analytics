# Swiggy SQL Case Study

## Project Overview

This project focuses on analyzing a Swiggy SQL dataset to explore customer behavior, restaurant performance, order trends, revenue generation, and delivery partner activity.

Using MySQL, I worked with relational data to solve business-oriented analytical problems and derive insights that support data-driven decision-making.

## Objectives

- Analyze customer distribution and ordering behavior.
- Evaluate restaurant ratings and revenue performance.
- Explore customer ordering patterns and inactive customers.
- Examine delivery partner activity and customer relationships.
- Apply SQL techniques to solve practical business problems.

## Tools & Technologies

- **Database:** MySQL
- **Query Language:** SQL
- **Concepts:** Joins, aggregate functions, GROUP BY, HAVING, subqueries, date functions and many other functions.

## Key Learning Outcomes

- Strengthened my understanding of relational databases and table relationships.
- Practiced writing SQL queries using joins, filtering, grouping, and aggregations.
- Applied analytical thinking to translate business requirements into SQL queries.
- Explored customer behavior, restaurant performance, and delivery operations.
- Improved my ability to approach business case studies using SQL.
